Follow these steps to start the OCR server

  1. 1
    Open a terminal in the backend directory
    cd backend
    Or double-click start_backend.bat in the backend folder.
  2. 2
    Install Python dependencies (first time only)
    pip install -r requirements.txt
    EasyOCR models (~200 MB) load on first startup.
  3. 3
    Start the Flask OCR server
    python app.py
    Server runs on http://localhost:5001 — keep terminal open.
